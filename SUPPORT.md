# Support Policy for DX-OS

Welcome to the DX-OS community! We want to help you get the most out of DX-OS. Here are the recommended ways to get support, report issues, and connect with the community.

---

## 1. Documentation & Guides

Before opening an issue, check our documentation:
- **Quick Start & Overview**: [README.md](README.md)
- **Getting Started**: [docs/getting-started.md](docs/getting-started.md)
- **Building from Source**: [docs/build-from-source.md](docs/build-from-source.md)
- **Local Development**: [docs/development.md](docs/development.md)
- **Architecture Decisions**: [docs/adr/README.md](docs/adr/README.md)

---

## 2. Community Discussions

For general questions, architecture discussions, ideas, and troubleshooting:
- **GitHub Discussions**: [https://github.com/ROYCE-8425/open_source/discussions](https://github.com/ROYCE-8425/open_source/discussions)
  - **Q&A**: Ask technical questions about setup, configuration, or workflows.
  - **Ideas**: Suggest new features or architectural ideas.
  - **Show and Tell**: Share custom marketing workflows and extensions you've built.

---

## 3. Bug Reports & Feature Requests

- **Bug Reports**: If you've found a bug in DX-OS, please submit a bug report via [GitHub Issues](https://github.com/ROYCE-8425/open_source/issues) using the bug report template.
- **Feature Requests**: To request enhancements, please submit a feature request issue after checking existing issues and discussions.

---

## 4. Security Vulnerabilities

Please **do not** open public issues for security vulnerabilities.
Refer to [SECURITY.md](SECURITY.md) for instructions on confidential disclosure.

---

## 5. Commercial & Enterprise Inquiries

DX-OS is 100% open-source software under the Apache-2.0 license. For enterprise deployment consulting, bespoke integrations, or corporate support inquiries, please contact the maintainers via [MAINTAINERS.md](MAINTAINERS.md).
